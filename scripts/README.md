# scripts/

Index des scripts utilitaires du repo. Convention de statut :

- `[actif]` : reference par `package.json`, `.github/workflows/` ou `docs/` - fait partie de l'outillage courant.
- `[one-off, conserve pour reference]` : ecrit pour une operation ponctuelle (backfill, cleanup, diagnostic, remediation). Conserve comme trace et comme exemple de plomberie (Odoo XML-RPC, pg-meta, Eduvia). **Ne pas relancer un one-off sans relire son contenu** : les donnees, ids et etats qu'il cible datent de son ecriture.

La plupart des scripts se lancent via `npx tsx scripts/<nom>.ts` (certains exigent `--env-file=.env.local`, voir l'en-tete de chaque fichier).
